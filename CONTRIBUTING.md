# Contributing

1. Fork, then `npm ci && npm run dev`.
2. Keep changes small. Run `npx tsc --noEmit -p .` and `npm run build` before a PR.
3. For visual changes, attach a still (`npx remotion still ...`) for 16:9 and 9:16.
4. Persian copy should be natural, short and correct (RTL, half-space ‌ where needed).
5. See `AGENTS.md` for project rules. These rules also apply to AI assistants.
