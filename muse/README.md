# راهنمای نصب استودیو موشن علی روی Muse

## بهترین مسیر: «Muse کارگردان، ابر رندرکننده»
- Muse متن، سناریو و props را می‌نویسد.
- Muse برای بازبینی، فریم ثابت (still) می‌گیرد.
- Shortsها و پیش‌نمایش‌ها را Muse خودش رندر می‌کند.
- درس‌های بلند به صف ابری رایگان (GitHub Actions) فرستاده می‌شوند.
- در پایان Muse کیفیت را بررسی می‌کند (QA) و فایل را تحویل می‌دهد.

چرا این مسیر:
- کامپیوتر Muse فقط ۲ هستهٔ CPU و حدود ۸ گیگ رم دارد و GPU ندارد. رندر ۱۰۰ ثانیه درس روی آن حدود ۱۳ دقیقه طول می‌کشد.
- صف ابری همان کار را بدون مصرف وقت Muse انجام می‌دهد.

## مشخصات کامپیوتر Muse
| مورد | مقدار |
|---|---|
| CPU / RAM | ۲ هسته AMD EPYC، حدود ۷.۷ گیگ، بدون swap |
| سیستم‌عامل | Ubuntu 24.04 (systemd-nspawn) |
| فضای دائمی | فقط `/home/hatch` (۱۰۰ گیگ) |
| بعد از ری‌استارت | `apt`، `/tmp` و `/etc` پاک می‌شوند. نصب‌کننده همه‌چیز را در `~/.local` می‌گذارد و `boot.sh` کتابخانه‌های Chrome را خودکار برمی‌گرداند. |
| اینترنت | خروجی از طریق Sentinel است و هر دامنهٔ جدید باید یک‌بار تأیید شود. |

## نصب (فقط یک پیام)
متن [INSTALL_PROMPT.md](INSTALL_PROMPT.md) را کپی کن و در Muse بفرست. بقیهٔ کارها را Muse خودش انجام می‌دهد.

## زمان‌های اندازه‌گیری‌شده
این زمان‌ها روی ماشینی با همان مشخصات Muse (۲ هسته، ۷.۸ گیگ) اندازه‌گیری شده‌اند.

| کار | زمان |
|---|---|
| نصب کامل از صفر | حدود ۲ دقیقه |
| `ams render TipShort --draft` (پیش‌نمایش ۳۰ ثانیه) | ۶۶ ثانیه |
| `ams render TipShort` (۱۰۸۰×۱۹۲۰ کامل) | ۴ تا ۵ دقیقه |
| `ams render LogoIntro` | حدود ۱ دقیقه |
| `ams render LessonPro` (۱۰۳ ثانیه، ۱۰۸۰p) | حدود ۱۳ دقیقه. برای این بهتر است از `ams cloud` استفاده شود. |

## دستورها
```
ams doctor                      # بررسی سلامت
ams templates                   # فهرست قالب‌ها
ams sample TipShort             # ساخت فایل props نمونه برای ویرایش
ams course 3 --short            # جلسهٔ ۳ دوره → props آمادهٔ LessonPro
ams still TipShort out/TipShort.props.json   # فریم ثابت برای بازبینی
ams render TipShort --draft     # پیش‌نمایش سریع
ams render TipShort             # خروجی نهایی یوتیوب
ams cloud LessonPro <props> --title "جلسه ۳"   # رندر در ابر رایگان
ams status <jobId>
ams qa out/xxx.mp4              # ابعاد، بلندی صدا (LUFS)، فریم سیاه، contact sheet
```

## رفع مشکل
- **Sentinel جلوی دانلود را گرفت:** دامنه را دائمی تأیید کن و دوباره `install.sh` را اجرا کن. نصب‌کننده idempotent است، یعنی اجرای دوباره چیزی را خراب نمی‌کند.
- **بعد از ری‌استارت VM رندر خطای Chrome داد:** `bash ~/workspace/ali-motion-studio/muse/boot.sh` را اجرا کن.
- **دانلود Chrome گیر کرد:** `export AMS_BROWSER=/path/to/chrome-headless-shell`، مثلاً همان Playwright خود Muse.
- **کمبود رم یا کرش:** `AMS_CONCURRENCY=1 ams render ...`
- **اسکیل در Muse پیدا نشد:** به Muse بگو `~/workspace/skills/ali-motion-studio/SKILL.md` را بخواند و به‌عنوان اسکیل ذخیره کند. Meta روش نصب اسکیل سفارشی را رسماً مستند نکرده است، اما کاربران از همین روش استفاده می‌کنند.
