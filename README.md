# استودیو موشن علی · Ali Motion Studio

اپ رایگان و تحت وب برای ساخت موشن‌گرافیک و «ری‌موشن» حرفه‌ای با **تایپوگرافی فارسی درست** (وزیرمتن، استعداد، لاله‌زار) برای یوتیوب، Shorts و اینستاگرام — مخصوص نیچ آموزش پیانو و برندهای علی باغبانی، Pianova و Music Radio 69.

- نسخه وب (Cloudflare): https://ali-motion-studio.ali-bitcoin666.workers.dev
- نسخه وب (GitHub Pages): https://alibitcoin666-code.github.io/ali-motion-studio/

## چرا این معماری؟ (برای لپ‌تاپ ضعیف)
| بخش | فناوری | هزینه |
|---|---|---|
| موتور انیمیشن | [Remotion](https://www.remotion.dev) 4 (React) — رایگان برای افراد و تیم‌های تا ۳ نفر | رایگان |
| پیش‌نمایش زنده | `@remotion/player` | رایگان |
| رندر داخل مرورگر | `@remotion/web-renderer` (WebCodecs → MP4 H.264) | رایگان |
| رندر ابری بدون فشار به سیستم | Cloudflare Worker + KV (صف) → GitHub Actions (Chrome + FFmpeg) | رایگان (مخزن عمومی) |
| میزبانی | GitHub Pages + آینه روی Cloudflare Workers | رایگان |

## نسخهٔ ۳ (بازنویسی کامل)
- **معلم = لوگوی ALi Piano.IR**: لوگو به وکتور تبدیل شده و حالت‌های حرف زدن، اشاره، معرفی، دست تکان دادن، فکر کردن و جشن دارد. کلیدهای سیاهش هم‌زمان با کلمه‌ها تکان می‌خورند.
- **صدا-اول**: نریشن فارسی رایگان (Microsoft Neural: فرید یا دلارا) با زمان هر کلمه؛ طول صحنه، زیرنویس و حرکت معلم از روی صدای واقعی ساخته می‌شوند.
- **صدای پیانوی واقعی** (Salamander Grand، CC-BY)، موسیقی بستر و افکت‌های ساخته‌شده بدون کپی‌رایت، داکینگ خودکار زیر صدای گوینده، مسترینگ −۱۴ LUFS.
- **چهار تم**: نوآر عاجی، نیمه‌شب طلایی، کلیدهای نئون، استودیو کرم.
- **تایپوگرافی**: استعداد (تیتر)، وزیرمتن (متن)، لاله‌زار (زیرنویس Shorts)، میرزا (شعار)، Outfit (لاتین)، Bravura (نت‌نویسی).
- ورود زیپ دوره (`docs/COURSE_ZIP_FORMAT.md`)، راهنمای ساده (`docs/GUIDE_SIMPLE.md`)، رشد کانال (`docs/YOUTUBE_GROWTH.md`). متن‌باز (MIT)؛ برای ویرایش با هر هوش مصنوعی `AGENTS.md` را به آن بدهید.

## مشخصات خروجی
- MP4 · H.264 High · yuv420p · ۳۰fps · AAC ۳۲۰kbps · CRF 18 — مطابق [توصیه‌های آپلود یوتیوب](https://support.google.com/youtube/answer/1722171)
- صدا روی −۱۴ LUFS و −۱ dBTP؛ کنار ویدیو: زیرنویس SRT کلمه‌ای، فصل‌ها و MP3

## متن فارسی
- انیمیشن «کلمه‌به‌کلمه» (هرگز حروف را جدا نمی‌کند، پس اتصال حروف فارسی حفظ می‌شود) — طبق [راهنمای رسمی Remotion برای متن عربی/فارسی](https://github.com/remotion-dev/skills/blob/main/skills/remotion-markup/arabic-text.md)
- برای برجسته کردن، عبارت را بین ستاره بنویسید: `گام *دو ماژور* با دست چپ`
- اعداد خودکار فارسی می‌شوند (Vazirmatn FD)؛ نت‌ها و فرمول‌ها با `bdi` جهت درست دارند.

## استفاده
1. قالب را از ستون راست انتخاب کنید، برند را از بالا.
2. در تب «محتوا» متن‌ها و نت‌ها را بنویسید؛ پیش‌نمایش لحظه‌ای عوض می‌شود.
3. تب «خروجی»: «رندر در مرورگر» (Chrome/Edge جدید) یا «رندر ابری» (۵ تا ۱۵ دقیقه، بدون فشار به لپ‌تاپ).

هیچ چیزی خودکار منتشر نمی‌شود؛ فقط فایل MP4 تحویل داده می‌شود.

## توسعه
```bash
npm ci
npm run dev        # اپ
npm run studio     # Remotion Studio
node scripts/render-job.mjs --local TipShort            # رندر محلی با صدا، مسترینگ و SRT
node scripts/render-job.mjs --samples                   # ساخت صدای نمونه‌ها
```
- صف ابری: `.github/workflows/render-queue.yml` هر ۵ دقیقه (secret: `QUEUE_SECRET`)
- Worker: `worker/index.js` (bindings: `JOBS` KV، `QUEUE_SECRET`، `PAGES_ORIGIN`)

## پیشنهادهای ارتقا (نقشه راه)
1. **ورود MIDI**: فایل MIDI اجرای خودتان → نت‌های ریزان با زمان‌بندی واقعی.
2. **ضبط صدای خودتان** به‌جای TTS و هم‌ترازی کلمه‌ها با Whisper.
3. **تامبنیل خودکار** از قلاب هر ویدیو با معلم لوگو.
4. **ربات تلگرام**: متن را به ربات بفرست → ویدیو در چت خصوصی برگردد.
5. **رندر دسته‌ای ۲۶ جلسهٔ دوره** با یک کلیک (هر شب ۴ جلسه در صف ابری).
6. **قالب‌های بیشتر**: «قبل/بعد» اجرای شاگرد، شمارش معکوس تمرین، چالش جمعه.
