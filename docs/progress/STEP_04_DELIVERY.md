# مرحله ۴ — تحویل نهایی (Ali Motion Studio)

تاریخ: ۲۰۲۶-۱۱-۲۲ — وضعیت: تحویل شد

## آنچه تحویل شد
- اپ وب رایگان و سبک برای ساخت موشن‌گرافیک فارسی با فونت وزیرمتن، شخصی‌سازی‌شده برای ۳ برند قابل انتخاب: Ali Baghbani، Pianova، Music Radio 69.
- ۷ قالب ثابت: ویدیوی آموزشی پیانو، نکته و تکنیک پیانو، آکورد/اسکیل روز، نقل‌قول متحرک، اینترو برند، معرفی آهنگ، اندااسکرین.
- ۳ فرمت: 16:9 (یوتیوب)، 9:16 (Shorts)، 1:1.
- دو روش خروجی: رندر داخل مرورگر (Chrome/Edge جدید) و رندر ابری رایگان با صف خودکار (تاخیر ۵ تا ۱۵ دقیقه).
- ذخیره پروژه‌ها در مرورگر + Import/Export JSON.

## نکات مهم
- مخزن عمومی است، پس فایل‌های Release `renders` هم عمومی‌اند (لینک‌ها تصادفی‌اند ولی خصوصی نیستند).
- GitHub زمان‌بندی (cron) را بعد از ۶۰ روز بی‌فعالیتی مخزن متوقف می‌کند؛ با یک commit یا اجرای دستی دوباره فعال می‌شود.
- cron گیت‌هاب گاهی دیرتر از ۵ دقیقه اجرا می‌شود.
- کانال یوتیوب اصلی در Hard Freeze است؛ اپ هیچ چیزی را خودکار منتشر نمی‌کند.

## پیشنهادهای ارتقا (Roadmap در README)
۱. زیرنویس خودکار فارسی از فایل صوتی (Whisper روی Actions)
۲. وارد کردن MIDI و نمایش نت‌ها روی کیبورد به‌صورت خودکار
۳. قالب تامبنیل یوتیوب (خروجی PNG)
۴. ربات تلگرام برای ثبت کار رندر و دریافت فایل
۵. نسخه تولید دسته‌ای (Batch) از یک فایل CSV
۶. کتابخانه افکت صوتی و موسیقی پس‌زمینه بدون حق کپی
